## Review fixes

The independent Codex review found four issues, all addressed:

- Wallet results can arrive before MPC callbacks finish. The wallet adapter now resolves transaction hashes at `FINAL` before interpreting return values.
- Lessee withdrawals ignored the spending budget. Validation now uses the live allowance and the charge already committed at a replaced nonce.
- Mint progress disappeared on reload and crossed account boundaries. Progress now persists under the contract and account, restores the stream from Base, and discovers an already-minted title.
- Example-stream retries could fund twice. A durable server record now precedes funding. Retries return the original transaction or refuse an uncertain pending operation.

## Remaining limits

Cash-out records persist in this browser, not across devices. Keep browser data until the swap resolves. Unknown wallet approval outcomes remain blocked for manual recovery. Server example-stream records require persistent shared storage. Tidepool and public RPC availability remain external dependencies.

The NEAR Connect selector was opened and its testnet wallet list inspected. Meteor, Intear, and Nightly appear, along with Ledger, Ethereum Wallets, and NEAR CLI. The current MyNearWallet manifest lacks a testnet flag and is filtered out. The signing tests use real keys through the test binding; they do not certify every third-party wallet's own approval interface.

The final digest-pinned release build, Safe deployment, all four adversarial scenarios at Safe finality, and typed key deletion remain release work. No freeze was attempted.
